O que e JavaScript?
1.html
Basico console alert DOM getElementById setInterval

Crie uma pagina HTML que explique o que e JavaScript. A pagina deve conter:

  1. Uma breve explicacao sobre a historia do JavaScript (criado por Brendan Eich em 1995, padronizado como ECMAScript).
  2. Explicacao de que o JavaScript e uma linguagem executada no navegador (ambiente sandbox) e nao acessa recursos do sistema operacional diretamente.
  3. Exemplos de uso de document.getElementById(), console.log() e alert().
  4. Uma secao que explique brevemente o conceito de Event Loop: como o JavaScript executa codigo de forma assincrona mesmo sendo single-threaded. Inclua um paragrafo explicativo e um diagrama simples (pode ser feito com CSS/HTML) mostrando a pilha de chamadas (call stack), a fila de tarefas (task queue) e a fila de microtarefas (microtask queue).
  5. Um relogio digital ao vivo na pagina usando setInterval(): a cada segundo, atualize um elemento da pagina com a hora atual formatada (HH:MM:SS).
Dica
Use new Date().toLocaleTimeString() para obter a hora formatada, e setInterval(funcao, 1000) para atualizar a cada segundo.
// Exemplo do relogio: function atualizarRelogio() { const agora = new Date(); document.getElementById("relogio").textContent = agora.toLocaleTimeString(); } setInterval(atualizarRelogio, 1000);

Tipos de Variaveis e Operadores
2.html
Basico variaveis typeof coercao == vs === truthy/falsy

Crie uma pagina que explore os tipos de variaveis, operadores e particularidades do JavaScript:

  1. Declare variaveis dos tipos: string, number, boolean, null, undefined, object e array.
  2. Use typeof para exibir o tipo de cada variavel na pagina (em uma tabela estilizada).
  3. Demonstre operacoes entre tipos diferentes e exiba os resultados:
    • "5" + 3 (concatenacao)
    • "5" - 3 (coercao numerica)
    • "5" * "2"
    • true + 1
    • null + 5
  4. Comparacao == vs ===: crie uma secao que compare pares de valores usando ambos os operadores e mostre os resultados em uma tabela. Exemplos:
    • 0 == false vs 0 === false
    • "" == false vs "" === false
    • null == undefined vs null === undefined
    • "1" == 1 vs "1" === 1
  5. Exploracao de truthy/falsy: crie uma lista de valores e, para cada um, exiba se e truthy ou falsy usando Boolean(valor) ou !!valor. Valores para testar: 0, "", null, undefined, NaN, false, "0", "false", [], {}, 1, " ".
Conceito importante
Em JavaScript, == faz coercao de tipo antes de comparar, enquanto === compara valor e tipo sem coercao. A boa pratica e sempre usar ===.

Desafio do Event Loop
3.html
Intermediario Event Loop setTimeout Promise microtask macrotask

Crie uma pagina interativa que ajude a entender o funcionamento do Event Loop do JavaScript. A pagina deve apresentar trechos de codigo e pedir ao aluno que preveja a ordem de execucao antes de clicar em "Executar".

Desafio principal: apresente o seguinte codigo e peca ao aluno para prever a ordem de saida:

setTimeout(() => console.log("A"), 0); console.log("B"); Promise.resolve().then(() => console.log("C")); console.log("D"); // Qual a ordem de saida?
  1. Exiba o trecho de codigo acima na pagina com destaque de sintaxe.
  2. Crie um campo de texto onde o aluno digita sua previsao (ex.: "B, D, C, A").
  3. Ao clicar no botao "Executar", execute o codigo real e exiba a saida passo a passo, com um pequeno atraso entre cada linha para simular o processo (use setTimeout para revelar cada resultado progressivamente).
  4. Compare a resposta do aluno com o resultado real e indique se acertou ou errou.
  5. Exiba uma explicacao detalhada de por que a ordem e B, D, C, A:
    • B e D sao sincronos — executam imediatamente na call stack.
    • C e uma microtarefa (Promise) — executa apos o codigo sincrono, mas antes das macrotarefas.
    • A e uma macrotarefa (setTimeout) — executa por ultimo, apos as microtarefas.
  6. Desafios extras (opcionais): adicione mais 2-3 trechos de codigo com diferentes combinacoes de setTimeout, Promise.resolve().then() e codigo sincrono para o aluno praticar.

Calculo de IMC com if e switch
4.html
Intermediario if/else switch parseFloat DOM formulario

Crie uma pagina com um formulario para calcular o Indice de Massa Corporal (IMC):

  1. Campos de entrada: Nome, Peso (kg) e Altura (m).
  2. Ao clicar em "Calcular", obtenha os valores com document.getElementById() e converta com parseFloat().
  3. Calcule o IMC: IMC = peso / (altura * altura).
  4. Use if / else if / else para classificar o resultado:
    • Abaixo de 18.5: Abaixo do peso
    • 18.5 a 24.9: Peso normal
    • 25.0 a 29.9: Sobrepeso
    • 30.0 a 34.9: Obesidade grau I
    • 35.0 a 39.9: Obesidade grau II
    • 40.0 ou mais: Obesidade grau III
  5. Use switch para exibir uma imagem ou icone diferente para cada faixa (pode usar elementos HTML/CSS estilizados no lugar de imagens reais).
  6. Exiba o resultado formatado: "Ola, [Nome]! Seu IMC e [valor]. Classificacao: [faixa]."

Laboratorio de Strings
6.html
Intermediario strings metodos de string palindromo loops

Crie uma pagina que funcione como um laboratorio de manipulacao de strings. A pagina deve ter um campo de entrada de texto e varias secoes, cada uma realizando uma operacao diferente sobre o texto digitado:

  1. Inverter string: exiba o texto invertido. Use split("").reverse().join("") ou implemente com um loop for.
  2. Capitalizar palavras: transforme a primeira letra de cada palavra em maiuscula. Use split(" "), percorra o array e use charAt(0).toUpperCase().
  3. Contar vogais: conte e exiba o numero de vogais (a, e, i, o, u) presentes no texto, ignorando acentos e maiusculas/minusculas.
  4. Remover espacos extras: remova espacos duplicados e espacos no inicio/fim. Use trim() e uma expressao regular ou loop.
  5. Verificar palindromo: verifique se o texto e um palindromo (lido da mesma forma de tras para frente, ignorando espacos e maiusculas). Exiba "E palindromo!" ou "Nao e palindromo."
  6. Estatisticas do texto: exiba o numero total de caracteres, numero de palavras e numero de frases (contando pontos, exclamacoes e interrogacoes).

Todas as operacoes devem ser executadas em tempo real conforme o usuario digita (use o evento input), ou com um botao "Analisar".

Validador de Formulario com Eventos
11.html
Intermediario eventos validacao focus/blur input submit regex

Crie um formulario de cadastro com validacao em tempo real usando multiplos tipos de eventos JavaScript:

  1. Campos do formulario:
    • Nome completo (minimo 3 caracteres)
    • E-mail (deve conter @ e um dominio valido)
    • Senha (minimo 8 caracteres, pelo menos uma letra maiuscula e um numero)
    • Confirmacao de senha (deve ser igual a senha)
    • Idade (numero entre 16 e 120)
    • Curso (select com opcoes; nao pode ficar vazio)
  2. Eventos a implementar:
    • input — valide em tempo real conforme o usuario digita (mostrando mensagens como "Muito curto", "Formato invalido", etc.).
    • focus — ao focar em um campo, exiba uma dica sobre o que e esperado (ex.: "Minimo 8 caracteres, 1 maiuscula, 1 numero").
    • blur — ao sair do campo, faca a validacao final e mostre um indicador verde (valido) ou vermelho (invalido).
    • change — no campo select, valide a selecao.
    • submit — ao enviar o formulario, verifique se todos os campos estao validos. Se sim, exiba uma mensagem de sucesso. Se nao, destaque os campos com erro. Use event.preventDefault() para evitar o envio real.
    • keydown — no campo de idade, permita apenas numeros (bloqueie letras).
  3. Cada campo deve ter um indicador visual de status: borda verde quando valido, borda vermelha quando invalido, e uma mensagem de erro abaixo do campo.
Sobre expressoes regulares
Para validar o e-mail, use algo como: /^[^\s@]+@[^\s@]+\.[^\s@]+$/. Para a senha: /^(?=.*[A-Z])(?=.*\d).{8,}$/. Nao e necessario usar expressoes perfeitas — o objetivo e praticar logica de validacao.

Mini Agenda de Contatos com localStorage
12.html
Avancado localStorage JSON CRUD arrays de objetos DOM

Crie uma mini agenda de contatos que salve os dados no navegador usando localStorage. A aplicacao deve implementar as quatro operacoes basicas (CRUD):

  1. Criar (Create): formulario com campos Nome, Telefone e E-mail. Ao salvar, adicione o contato a um array e persista no localStorage.
  2. Ler (Read): ao carregar a pagina, leia os contatos salvos com JSON.parse(localStorage.getItem("contatos")) e exiba-os em uma tabela ou lista de cartoes.
  3. Atualizar (Update): adicione um botao "Editar" em cada contato. Ao clicar, preencha o formulario com os dados atuais e permita a edicao. Ao salvar, atualize o contato no array e no localStorage.
  4. Excluir (Delete): botao "Excluir" em cada contato, com uma confirmacao antes de remover (confirm()). Remova do array e atualize o localStorage.
  5. Busca: campo de busca que filtra os contatos por nome em tempo real (evento input).
// Salvar contatos no localStorage: function salvarContatos(contatos) { localStorage.setItem("contatos", JSON.stringify(contatos)); } // Carregar contatos do localStorage: function carregarContatos() { const dados = localStorage.getItem("contatos"); return dados ? JSON.parse(dados) : []; }

13.html

Crie o classico Jogo da Velha para dois jogadores. Este exercicio integra arrays, condicionais, loops, manipulacao do DOM e eventos — um projeto completo para consolidar os fundamentos:

  1. Tabuleiro: crie um grid 3x3 usando CSS Grid. Cada celula deve ser clicavel.
  2. Estrutura de dados: represente o tabuleiro como um array bidimensional 3x3, inicializado com valores vazios ("").
