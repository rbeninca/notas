PARTE 1

História do JavaScript

De 10 dias de protótipo à linguagem mais usada da Web

Linha do tempo do JavaScript

1995

Brendan Eich cria o Mocha em 10 dias na Netscape. Renomeado para LiveScript e depois JavaScript.

1997

ECMA-262 padroniza a linguagem como ECMAScript. Portabilidade entre navegadores.

2009

Ryan Dahl lança o Node.js: JS fora do navegador, no servidor, com I/O não-bloqueante.

2015

ES6: let, const, arrow functions, classes, Promises, módulos.

2026

Evolução anual. JS é a única linguagem nativa de todos os navegadores.

JavaScript ≠ Java. O nome foi uma estratégia de marketing da Netscape/Sun Microsystems em 1995. São linguagens com paradigmas, tipagem e ambientes de execução completamente distintos.

Ambiente de execução: sandbox

JavaScript no navegador executa em um sandbox: um ambiente isolado que não tem acesso direto ao sistema de arquivos, rede arbitrária ou hardware do usuário.

JS Pode (dentro do sandbox)
  • Manipular DOM
  • Requisições HTTP (fetch/XHR)
  • localStorage / sessionStorage
  • APIs com permissão (câmera, geo)
JS Não Pode (barreira de segurança)
  • Ler/escrever arquivos do SO
  • Executar programas locais
  • Acessar outras abas/domínios
  • Acesso direto à rede/hardware
Onde executar JS
  • Console do navegador (F12)
  • Tag <script> em HTML
  • Arquivo .js externo
  • Node.js no terminal

Eventos DOM e addEventListener

O navegador dispara eventos quando o usuário interage com a página. JavaScript pode escutar esses eventos e executar uma função de callback.

<button id="meuBtn">Clique aqui</button>
<p id="msg"></p>

<script>
  const btn = document.getElementById("meuBtn");
  const msg = document.getElementById("msg");

  btn.addEventListener("click", function() {
      msg.textContent = "Botão clicado!";
      msg.style.color = "#2e7d32";
  });
</script>
elemento.addEventListener(evento, callback)
Registra uma função que será chamada quando o evento ocorrer no elemento. O callback é assíncrono — fica aguardando na Web API até o evento acontecer.
Eventos comuns: click, input, submit, keydown, mouseover, load, scroll. Todos passam pelo Event Loop — o callback fica na fila até a Call Stack esvaziar.
PARTE 2

Event Loop

Modelo de concorrência single-thread com fila de callbacks

Como funciona o Event Loop?

// O código
1 setTimeout(() => console.log("A"), 0);
2 console.log("B");
3 Promise.resolve().then(() => console.log("C"));
4 console.log("D");
Resultado final no console:
B, D, C, A

Não é B, D, A, C — e não é na ordem do código!

● Call Stack

Executa o código síncrono (imediato). LIFO: último a entrar, primeiro a sair.

● Microtask Queue

Callbacks de Promise.then(). Tem prioridade sobre a Task Queue.

● Task Queue

Callbacks de setTimeout, eventos DOM, setInterval.

● Event Loop

Coordena: quando a Call Stack esvazia, executa Microtasks, depois Tasks.

setInterval — execução periódica

0
// Executa a função a cada 1000ms (1s)
let count = 0;
const id = setInterval(function() {
    count++;
    console.log(count);
}, 1000);

// Para parar:
clearInterval(id);
setInterval(callback, ms) → registra o callback na Web API. A cada ms milissegundos, o callback é enfileirado na Callback Queue. Retorna um id numérico para cancelamento via clearInterval(id).
setTimeout vs setInterval: setTimeout(cb, ms) executa o callback uma única vez após ms. setInterval(cb, ms) executa repetidamente a cada ms. Ambos são assíncronos e passam pelo Event Loop.
PARTE 3

Tipos e Variáveis

Tipagem dinâmica, primitivos, referência e declaração

Tipos em JavaScript

JavaScript possui tipagem dinâmica: o tipo é associado ao valor, não à variável. O operador typeof retorna o tipo em tempo de execução.

Primitivos (imutáveis, copiados por valor)

number
42, 3.14, NaN, Infinity
typeof 42 === "number"
string
"texto", 'abc', `${x}`
typeof "a" === "string"
boolean
true, false
typeof true === "boolean"
undefined
let x; // x === undefined
typeof x === "undefined"
null
let y = null;
typeof null === "object" (!)
bigint
9007199254740993n
typeof 1n === "bigint"
symbol
Symbol("id")
typeof Symbol() === "symbol"

Referência (mutáveis, copiados por referência)

Object
{ nome: "Ana", idade: 22 }
Array
[1, 2, 3]
Function
function() {}

Coerção de tipo e comparação

Coerção implícita: o motor converte tipos automaticamente em certas operações.

// Concatenação (string + qualquer)
"5" + 3       // "53" (number -> string)
"5" - 3       // 2   (string -> number)

// Booleano implícito
Boolean(0)    // false (falsy)
Boolean("")   // false
Boolean(null) // false
Boolean(1)    // true  (truthy)
Boolean("a")  // true

PARTE 4

Arrays e Objetos

Estruturas de dados fundamentais em JavaScript

Arrays — coleções indexadas

Um array é uma lista ordenada de valores, indexada a partir de 0. Aceita tipos heterogeneos.

const frutas = ["maca", "uva", "pera"];

// Acesso e modificação
frutas[0]          // "maca"
frutas[2] = "kiwi" // substitui "pera"

// Métodos essenciais
frutas.push("manga")  // adiciona ao final
frutas.pop()           // remove do final
frutas.length          // tamanho atual

// Verificação
Array.isArray(frutas)  // true
typeof frutas          // "object" (!)
// Iteração
for (let i = 0; i < frutas.length; i++) {
    console.log(frutas[i]);
}

// for...of (ES6, mais legível)
for (const fruta of frutas) {
    console.log(fruta);
}

// Desestruturação
const [a, b] = frutas;
// a = "maca", b = "uva"

Objetos — pares chave-valor

Objetos armazenam propriedades como pares chave: valor. As chaves são strings (ou Symbols); os valores podem ser de qualquer tipo.

const aluno = {
    nome: "Ana Silva",
    idade: 22,
    ativo: true,
    notas: [8.5, 9.0, 7.0]
};

// Acesso
aluno.nome       // "Ana Silva"
aluno["idade"]   // 22

// Modificar / adicionar
aluno.email = "ana@email.com";

// Desestruturação
const { nome, idade } = aluno;
Referência: atribuir um objeto a outra variável não copia os dados — ambas apontam para o mesmo objeto na memória. const b = aluno; b.nome = "Bia"; → aluno.nome também será "Bia".

Controle de Fluxo

Estruturas de seleção e repetição

Estruturas de seleção

if / else if / else

const nota = 7.5;

if (nota >= 9) {
    console.log("A");
} else if (nota >= 7) {
    console.log("B");  // executa
} else if (nota >= 5) {
    console.log("C");
} else {
    console.log("D");
}

switch

const dia = "seg";

switch (dia) {
    case "seg":
    case "ter":
    case "qua":
    case "qui":
    case "sex":
        console.log("Dia útil");
        break;
    case "sab":
    case "dom":
        console.log("Fim de semana");
        break;
    default:
        console.log("Inválido");
}

Ternário

const status = nota >= 7
    ? "Aprovado"
    : "Reprovado";

// Equivale a:
// if (nota >= 7) {
//   status = "Aprovado";
// } else {
//   status = "Reprovado";
// }

Estruturas de repetição

for classico

for (let i = 0; i < 5; i++) {
    console.log(i); // 0,1,2,3,4
}

while / do...while

let n = 1;
while (n <= 100) {
    n *= 2; // dobra até passar de 100
}
console.log(n); // 128

// do...while: executa ao menos 1 vez
let entrada;
do {
    entrada = prompt("Senha:");
} while (entrada !== "1234");

for...of (iteráveis)

const cores = ["red", "green", "blue"];

for (const cor of cores) {
    console.log(cor);
}
// "red", "green", "blue"

// Também funciona com strings:
for (const ch of "IFSC") {
    console.log(ch);
}
// "I", "F", "S", "C"
break interrompe o laço. continue pula para a próxima iteração. Use com parcimônia para manter a legibilidade.

Integração: exemplo completo

Combinando arrays, objetos, for...of e if/else em um cenário realista:

const alunos = [
    { nome: "Ana",   notas: [8.5, 9.0, 7.0] },
    { nome: "Bruno", notas: [5.0, 6.5, 4.0] },
    { nome: "Carla", notas: [10,  9.5, 9.0] }
];

for (const aluno of alunos) {
    // Calcula média aritmética
    let soma = 0;
    for (const nota of aluno.notas) {
        soma += nota;
    }
    const media = soma / aluno.notas.length;

    // Classifica resultado
    let resultado;
    if (media >= 7) {
        resultado = "Aprovado";
    } else if (media >= 5) {
        resultado = "Recuperação";
    } else {
        resultado = "Reprovado";
    }

    console.log(`${aluno.nome}: média ${media.toFixed(1)} - ${resultado}`);
}
// Ana: média 8.2 - Aprovado
// Bruno: média 5.2 - Recuperação
// Carla: média 9.5 - Aprovado

Recapitulação

História

Criado em 1995, padronizado pela ECMA, evoluiu até ES2026+. Única linguagem nativa dos navegadores.

Event Loop

Single-thread + Web APIs + Callback Queue. Operações assíncronas não bloqueiam a thread principal.

Tipos

7 primitivos (number, string, boolean, undefined, null, bigint, symbol) + referência (Object, Array, Function).

Variáveis

const (padrão), let (reatribuição), ambos com escopo de bloco. Evitar var.
