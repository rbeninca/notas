## Encontro 1 — Fundamentos da Web, Cliente-Servidor, HTTP e HTML5 completo
 
**Conteúdo**
- Internet × Web, cliente-servidor, navegador, servidor, URL, DNS
- HTTP: requisição/resposta, métodos, códigos de status
- HTML5: estrutura mínima, texto, listas, links, imagens, tabelas, formulários, tags semânticas (header, nav, main, section, article, aside, footer)
**Sequência do encontro (240 min)**
| Bloco | Tempo | Atividade |
|---|---|---|
| Abertura | 15 min | Apresentação do plano de ensino, critérios de avaliação e do produto final da disciplina |
| Exposição — Web e HTTP | 40 min | História, cliente-servidor, anatomia de URL, DNS, ciclo HTTP com DevTools ao vivo |
| Exposição — HTML5 | 45 min | Estrutura, tags de texto/lista/link/imagem/tabela/formulário, semântica |
| Prática guiada | 80 min | Construção coletiva, passo a passo, de um mini-site de 3 páginas (apresentação, conteúdo técnico, formulário) |
| Prática autônoma | 40 min | Aluno finaliza sozinho a terceira página e valida o HTML em validator.w3.org |
| Fechamento | 20 min | Checklist do que foi entregue + introdução ao estudo EAD 1 |
 
**Atividades**
- Mini-site de 3 páginas em HTML puro (sem CSS ainda), navegação entre as páginas funcionando.
- Validação do HTML no validador do W3C.
**Estudo EAD vinculado — Bloco 1 (4h): HTML completo**
- Lista de exercícios objetivos sobre tags semânticas, tabelas e formulários.
- Exercício aberto: refatorar uma página com `div`s genéricas para tags semânticas corretas.

## Encontro 9 — JavaScript fundamentos I: história, sandbox, event loop, tipos, variáveis, arrays, objetos, seleção e repetição
 
**Conteúdo**
- Introdução histórica do JavaScript: origem (Netscape, Brendan Eich), evolução, ECMAScript, papel atual
- O que é um sandbox (segurança do navegador, isolamento de execução)
- Event loop: como o JS processa código assíncrono (call stack, callback queue, event loop)
- Exemplo prático de `setInterval` para demonstrar o event loop em ação
- Tipos primitivos (`number`, `string`, `boolean`, `null`, `undefined`), `typeof`, coerção de tipos
- Variáveis: `let`/`const` (e por que evitar `var`), escopo de bloco
- Arrays: criação, acesso por índice, `push`, `pop`, `length`, iteração básica
- Objetos literais: criação, acesso a propriedades (ponto e colchete), objetos aninhados
- Estruturas de seleção: `if/else`, `switch`, operador ternário
- Estruturas de repetição: `for`, `while`, `for...of`
**Sequência do encontro (240 min)**
| Bloco | Tempo | Atividade |
|---|---|---|
| Devolutiva da Avaliação 1 | 15 min | Pontos recorrentes de erro, o que revisar |

| Demonstração — `setInterval` | 15 min | Exemplo prático de `setInterval` para visualizar o event loop em ação (contador, relógio) |
| Exposição — Tipos e variáveis | 25 min | Tipos primitivos, `typeof`, coerção, `let`/`const`/`var`, escopo de bloco |
| Exposição — Arrays e objetos | 25 min | Arrays (criação, acesso, `push`/`pop`, iteração), objetos literais (criação, acesso por ponto/colchete) |
| Prática guiada | 35 min | Scripts no console explorando tipos, variáveis, arrays e objetos |
| Exposição — Seleção e repetição | 30 min | `if/else`, `switch`, ternário, laços `for`/`while`/`for...of` |
| Prática guiada | 40 min | Exercícios de lógica com arrays e objetos: validações, iteração, FizzBuzz, filtrar lista de objetos |
| Fechamento | 20 min | Checklist + introdução ao estudo EAD 4 (parte 1) |
 
**Atividades**
