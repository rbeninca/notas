## Encontro 9 — Arrays
 
**Conteúdo**
- Arrays: `push`, `pop`, `slice`, `splice`, `sort`, `includes`, iteração (`forEach`)
- Mutabilidade, cópia rasa vs referência
- Menção conceitual a Typed Arrays: o array comum do JS **não é homogêneo** (guarda tipos misturados); quando é preciso trabalhar com dados binários de tamanho/tipo fixo existem os Typed Arrays (`Int8Array`, `Uint8Array`, `Float32Array`, sobre um `ArrayBuffer`). Objetivo aqui é apenas **saber que existem e por quê** — sem prática de bytes.
**Sequência do encontro (240 min)**

|---|---|---|
| Retomada | 15 min | Dúvidas do EAD 4 (parte strings/funções) |

| Prática guiada | 80 min | Manipulação de uma lista de dados fictícia (ex.: lista de produtos/alunos): ordenar, filtrar manualmente, buscar |
| Prática autônoma | 50 min | Aluno resolve sozinho uma lista de desafios com arrays sobre um conjunto de dados dado |
| Menção — Typed Arrays | 15 min | Array do JS não é homogêneo; existe o Typed Array como alternativa para dados binários de tipo fixo — só sinalizar que existe e quando lembrar dele |
| Fechamento | 20 min | Checklist + introdução ao estudo EAD 5 |
 
**Atividades**
- Script de manipulação de lista de dados com arrays comuns.
- (Sem prática de Typed Array — apenas registro conceitual.)
**Estudo EAD vinculado — parte do Bloco 5 (Objects e JSON — dividir 4h)**
