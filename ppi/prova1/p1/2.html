Questão 2 — CSS, cascata e especificidade

Analise os elementos e as regras CSS. Não há outras folhas de estilo. Considere a cor do texto, não a cor do fundo. 

<div id="painel">
  <p class="aviso">A <span>B</span></p>
  <p>C</p>
</div>

<style>
  p                    { color: black; }
  .aviso               { color: green; }
  #painel p            { color: blue; }
  #painel .aviso       { color: red; }
  span                 { color: orange; }
</style>

Item a [0,9] — cores finais

Resposta: A fica red, B fica orange e C fica blue.

Para A, que está no parágrafo class="aviso", a regra vencedora é #painel .aviso, que define red. Para C, a regra mais específica que o atinge é #painel p, que define blue. O texto B está em um span e recebe a cor explícita orange da regra span.

Item b [0,8] — especificidade e herança

Resposta: A e C têm cores diferentes porque A também corresponde às regras de classe .aviso e #painel .aviso; C não corresponde a elas. B não herda o vermelho de A porque tem uma declaração própria de cor.

A regra #painel .aviso tem especificidade maior que #painel p e vence para A. O parágrafo C não tem a classe aviso, então nele vence #painel p (azul). Comparando as partes dos seletores: #painel .aviso tem 1 ID e 1 classe; #painel p tem 1 ID e 1 elemento. O ID empata, e a classe tem prioridade sobre o elemento, por isso a regra de A vence. A regra simples p é menos específica que ambas. Embora um span normalmente herde a cor do texto de seu pai, uma declaração aplicada diretamente a ele — neste caso span { color: orange; } — prevalece sobre a cor herdada.

Item c [0,8] — deixar somente C roxo

Uma regra possível: #painel p:not(.aviso) { color: purple; } 

#painel p:not(.aviso) { color: purple; }

O seletor encontra parágrafos dentro de #painel que não têm a classe aviso: nessa marcação, somente C. A regra é específica o bastante para vencer #painel p. Como ela não seleciona A, não altera sua cor; também não seleciona o span B, que permanece laranja.

:not(.aviso) exclui A e contribui com a especificidade da classe .aviso; a regra completa também contém o ID #painel e o elemento p.
