Questão 3 — Flexbox e posicionamento

Uma linha flexível tem 440 px de largura, sem padding ou bordas. Os conteúdos são curtos e não impedem a redução dos cartões. Considere a borda esquerda da linha como x = 0. 

<div class="linha">
  <div class="card">A</div>
  <div class="card importante">
    B <span class="selo">Novo</span>
  </div>
  <div class="card">C</div>
</div>

<style>
  .linha { display: flex; width: 440px; gap: 20px; }
  .card { flex: 1 1 100px; min-width: 0; }
  .importante { flex-grow: 2; position: relative; }
  .selo { position: absolute; top: 0; right: 0; }
</style>

Item a [1,0] — largura final dos cartões

Resposta: A = 125 px, B = 150 px e C = 125 px.

  1. Os três cartões começam com base de 100 px: 3 × 100 = 300 px.
  2. Os dois gaps ocupam 2 × 20 = 40 px. Restam para os cartões 440 − 300 − 40 = 100 px de espaço livre.
  3. Os fatores de crescimento são 1 para A, 2 para B e 1 para C; a soma é 1 + 2 + 1 = 4. Cada unidade recebe 100 ÷ 4 = 25 px.
  4. A recebe 25 px e termina com 100 + 25 = 125 px. B recebe 2 × 25 = 50 px e termina com 150 px. C recebe 25 px e termina com 125 px.

Verificação: 125 + 150 + 125 + 20 + 20 = 440 px.

Item b [0,6] — posição horizontal de B e C

Resposta: B começa em x = 145 px e C começa em x = 315 px.

A começa em x = 0 e tem 125 px de largura. Depois do gap de 20 px, B começa em 0 + 125 + 20 = 145 px. B tem 150 px; somando o segundo gap, C começa em 145 + 150 + 20 = 315 px.

Item c [0,9] — posição e fluxo do selo

Resposta: o selo aparece no canto superior direito do cartão B. O cartão .importante é a referência de posição; o selo não aumenta a largura de B.

position: relative em .importante estabelece o bloco de referência para o descendente absoluto. No selo, top: 0 e right: 0 alinham sua caixa ao canto superior direito desse cartão. Como position: absolute remove o selo do fluxo normal, ele não participa do cálculo de largura dos itens Flexbox nem reserva espaço dentro de B.
