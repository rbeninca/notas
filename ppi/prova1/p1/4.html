Questão 4 — Grid, responsividade e animação

O código deveria distribuir os artigos em três colunas nas telas largas e duas nas estreitas. Analise a distribuição antes do deslocamento visual da animação. 

<main class="grade">
  <article class="destaque">A</article>
  <article>B</article>
  <article>C</article>
  <article>D</article>
</main>

<style>
  .grade { display: grid;
           grid-template-columns: repeat(3, 1fr); gap: 10px; }
  .destaque { grid-column: 1 / 4;
              animation: mover 2s linear infinite alternate; }
  @media (max-width: 600px) {
    .grade { grid-template-columns: repeat(2, 1fr); }
  }
  @keyframes mover {
    from { transform: translateX(0); }
    to   { transform: translateX(20px); }
  }
</style>

Item a [0,6] — distribuição em janela de 800 px

Resposta: há três colunas explícitas. A ocupa a primeira linha inteira; B, C e D ficam, respectivamente, nas colunas 1, 2 e 3 da segunda linha.

A largura de 800 px não satisfaz max-width: 600px, portanto a regra de três colunas permanece ativa. O posicionamento grid-column: 1 / 4 faz A começar na linha de coluna 1 e terminar na linha 4, abrangendo as três colunas.

Item b [0,8] — terceira coluna implícita e correção

Resposta: em 500 px a media query define duas colunas explícitas, mas grid-column: 1 / 4 ainda exige que A vá da linha 1 à linha 4, um intervalo de três colunas. O Grid pode criar a terceira coluna como trilha implícita. Troque somente para grid-column: 1 / -1. 

.destaque { grid-column: 1 / -1; }

O valor -1 aponta para a última linha da grade explícita. Assim, A abrange toda a grade explícita disponível: três colunas na tela larga e duas na estreita, sem exigir uma trilha implícita extra.

Item c [0,6] — distribuição corrigida em janela de 500 px

Resposta: A ocupa a primeira linha nas duas colunas; B e C ocupam, respectivamente, a primeira e a segunda coluna da segunda linha; D começa na primeira coluna da terceira linha.

Depois que A ocupa as duas células da primeira linha, o posicionamento automático segue preenchendo as próximas células livres na ordem: B, C e D.

Item d [0,5] — deslocamento após 1 segundo

Resposta: após 1 segundo, A deslocou-se 10 px para a direita. O movimento não altera a posição reservada para os outros artigos.

A animação é linear e leva 2 segundos para ir de translateX(0) a translateX(20px). Um segundo é metade da duração, portanto o deslocamento é 20 × (1 ÷ 2) = 10 px. A propriedade transform altera a apresentação visual, não o espaço que o Grid reservou no layout; B, C e D mantêm suas posições calculadas.
