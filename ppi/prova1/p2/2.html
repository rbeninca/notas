Questão 2 — Cascata e especificidade CSS (2,0 pontos)

Considere o HTML e o CSS abaixo. Qual será a cor da palavra “Aviso!” e qual justificativa está correta? 

<style>
  #conteudo p { color: blue; }
  p.alerta { color: green; }
  p#mensagem { color: purple; }
  .alerta { color: red; }
</style>
<section id="conteudo">
  <p id="mensagem" class="alerta">Aviso!</p>
</section>

Alternativas

Errado. A regra azul e p#mensagem têm a mesma especificidade. Nesse empate, vence a regra declarada mais tarde, que define roxo.

Errado. Seletor com ID tem maior especificidade que seletor com classe. p.alerta perde para p#mensagem.

Errado. A ordem só desempata regras com a mesma especificidade. .alerta é menos específica que os seletores que contêm um ID.

Errado. Os dois seletores têm um ID e uma tag, portanto possuem a mesma especificidade. Como p#mensagem vem depois, a cor final é roxa.

Errado. Embora a cor roxa esteja correta, .alerta não é a regra vencedora: ela tem menor especificidade. A vencedora é p#mensagem, que empata com #conteudo p e aparece depois.

Por que a alternativa C? #conteudo p e p#mensagem têm a mesma especificidade: um ID e um seletor de elemento cada. Como p#mensagem aparece depois no CSS, sua declaração color: purple prevalece.
