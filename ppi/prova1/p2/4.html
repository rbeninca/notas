Questão 4 — Grid responsivo e animação CSS (2,0 pontos)

Em uma janela de 500 px de largura, qual alternativa descreve corretamente o layout e a animação de A? 

<style>
  .grade { display: grid; grid-template-columns: repeat(2, 1fr); gap: 10px; }
  .destaque { grid-column: 1 / 3; animation: pulsar 2s infinite alternate; }
  @keyframes pulsar {
    from { opacity: 1; }
    to   { opacity: 0.5; }
  }
  @media (max-width: 600px) {
    .grade { grid-template-columns: 1fr; }
  }
</style>
<div class="grade">
  <article class="destaque">A</article>
  <article>B</article>
  <article>C</article>
</div>

Alternativas

Errado. A media query altera somente grid-template-columns; ela não redefine grid-column. A regra grid-column: 1 / 3 continua valendo.

Errado. Grid não impede animações CSS. A propriedade animation aplicada diretamente a A executa normalmente, alternando sua opacidade entre 1 e 0.5.

Errado. alternate faz a animação inverter a direção a cada ciclo; não define uma opacidade fixa. A regra de coluna 1 / 3 também continua ativa, então A abrange duas colunas.

Errado. A posição não é inválida: se a grade não tem uma segunda coluna explícita, o Grid pode criar uma coluna implícita para atender ao posicionamento. O item não desaparece.

Errado. O Grid não converte automaticamente colunas em linhas. grid-column: 1 / 3 especifica linhas de coluna e faz A abranger duas colunas, inclusive quando uma delas é implícita.

Resumo: a media query troca a grade para uma coluna explícita, mas não sobrescreve grid-column: 1 / 3; essa posição pode gerar uma segunda coluna implícita. Já alternate inverte a direção da animação em cada ciclo de 2 segundos, fazendo a opacidade variar entre 1 e 0.5.
